## 4.16 数字和计数
### 4.16.1 数字系统

### 4.16.3 时间
用法公式：（时针）
1. **数字 + 時（じ）**
数字与「時」合用表示时针，即几点。
2. **（例外）四点 - よじ**
3. **（例外）七時 - しちじ**
4. **（例外）九時 - くじ**

用法公式：（分针）
1. **数字 + 分（ふん）**
数字与「分」合用表示分针，即几分。
2. **（例外）一分 - いっぷん**
3. **（例外）三分 - さんぷん**
4. **（例外）四分 - よんぷん**
5. **（例外）六分 - ろっぷん**
6. **（例外）八分 - はっぷん**
7. **（例外）十分 - じゅっぷん**

用法公式：（秒针）
1. **数字 + 秒（びょう）**

示例：
1. 1時24分（いちじ・にじゅうよんぷん）
*1:24*
2. 午後4時10分（ごご・よじ・じゅっぷん）
*4:10 PM*
3. 午前9時16分（ごぜん・くじ・じゅうろっぷん）
*9:16 AM*
4. 13時16分（じゅうさんじ・じゅうろっぷん）
*13:16*
5. 2時18分13秒（にじ・じゅうはっぷん・じゅうさんびょう）
*2:18:13*

### 4.16.4 时间跨度
用法公式：
1. **数字 + 時/日/週/年 + 間（かん）**
時/日/週/年与「かん」合用表示时间跨度。
2. **数字 + 分/秒**
分/秒可以直接表示时间跨度，不需要加「かん」。
3. **（特例）一日（いちにち）**
4. **（特例）一週間（いっしゅうかん）**
5. **（特例）八週間（はっしゅうかん）**

示例：
1. 二時間四十分（にじかん・よんじゅっぷん）
*2小时40分钟*
2. 二十日間（はつかかん）
*20天*
3. 十五日間（じゅうごにちかん）
*15天*
4. 二年間（にねんかん）
*两年*
5. 三週間（さんしゅうかん）
*三周*
6. 一日（いちにち）
*一天*

用法公式：
1. **数字 + ヶ月（かげつ）**
数字与「ヶ月」合用表示月份的时间跨度。
\*其中，「ヶ」与片假名「ケ」无关，而是这个量词对应的汉字「箇」的简写。
2. **（特例）一ヶ月（いっかげつ）**
3. **（特例）六ヶ月（ろっかげつ）**
4. **（特例）十ヶ月（じゅっかげつ）**

示例：
1. 十一ヶ月（じゅういっかげつ）
*11 个月*
2. 二十ヶ月（にじゅっかげつ）
*20 个月*
3. 三十三ヶ月（さんじゅうさんかげつ）
*33 个月*

### 4.16.6 用「目」来表示顺序
用法公式：
1. **数字 + 量词 + 目（め）**
量词与「目」合用表示第几个。

示例：
1. 二回目
*第二次*
2. 四人目
*第四个人*
